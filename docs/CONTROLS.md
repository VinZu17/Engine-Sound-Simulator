# Controls Reference

This page is a quick reference for the keyboard controls used by the Engine Sound Simulator.

## Engine

| Key | Action |
| --- | --- |
| `R` | Toggle ignition on/off |
| `E` (hold) | Crank the starter motor |
| `Space` | Apply throttle |
| `B` | Apply brake |
| `C` (hold) | Disengage the clutch |

## Transmission

| Key | Action |
| --- | --- |
| `Arrow Up` | Shift up |
| `Arrow Down` | Shift down |

## Basic Startup Sequence

1. Press `R` to switch the ignition on.
2. Hold `E` until the engine starts.
3. Release `E` after the engine is running.
4. Hold `Space` to increase throttle and RPM.
5. Use `C` when changing gears.
6. Use the arrow keys to shift through the gearbox.

## Tips

- Keep the clutch disengaged while changing gears for smoother operation.
- If the engine is off, verify that the ignition is enabled before using the starter.
- If keyboard input does not respond, click the simulator page first to restore browser focus.
